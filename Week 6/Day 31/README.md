## 🧠 Ключевые концепции:

### Как ПК видит картинки:
- Чёрно-белое: таблица чисел (28, 28)
- Цветное: 3 таблицы RGB (28, 28, 3)
- Нормализация: /255 → значения 0-1

### Свёртка (главное):
- Фильтр 3x3 скользит по картинке
- Умножает и суммирует → одно число
- Разные фильтры находят разные паттерны
- В CNN фильтры обучаются сами!

### Pooling:
- Max Pooling: берёт максимум из области 2x2
- Уменьшает размер в 2 раза
- Оставляет самое важное

### CNN архитектура:
```
Вход → Conv → Pool → Conv → Pool → Flatten → Dense → Выход
```
